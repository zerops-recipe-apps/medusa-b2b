# Medusa B2B (backend)

Medusa v2.21 B2B API and admin. This repo is **backend only** (app at repository root).

Storefront: [medusa-b2b-nextstore](https://github.com/zerops-recipe-apps/medusa-b2b-nextstore).

Recipe: [`zeropsio/recipes/medusa-b2b`](https://github.com/zeropsio/recipes/tree/main/medusa-b2b) and [`.zerops-recipe/`](.zerops-recipe/).

## Local dev

```bash
yarn install
yarn dev          # http://localhost:9000 — admin at /app
```

Optional storefront (separate clone):

```bash
cd ../medusa-b2b-nextstore && yarn dev   # :8000
```
