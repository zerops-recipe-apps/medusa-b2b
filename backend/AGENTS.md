# backend (Medusa B2B)

Medusa v2.21 API + admin (Yarn **1.22**). Part of [medusa-b2b](../) — see root [`AGENTS.md`](../AGENTS.md).

- Hostname / `zeropsSetup`: `medusa` — port `9000`, admin at `/app`
- Setup in root [`zerops.yml`](../zerops.yml) — `cd backend` for build; runtime is flattened to `/var/www`
- Dev: `yarn dev` from this directory
